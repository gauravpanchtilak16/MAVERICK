## Use this kit

1. Read `HANDBOOK_COMPLIANCE_CHECKLIST.md` first. The supplied local handbook is the operational authority for your event.
2. Put `AGENTS.md` (or `PROJECT_INSTRUCTIONS.md`) in the project root and paste it into your coding agent's project instructions/context if the tool does not read it automatically. Keep it available throughout development.
3. Follow `PROMPT_PACK.md` one stage at a time. Do not ask an agent to generate the entire product in one giant prompt.
4. Use `SCIENCE_AND_DATA_REGISTER.md` to avoid false scientific claims and track every data source.
5. Start `README_TEMPLATE.md` immediately and update it as the product changes.
6. Track every genuine human push in `HOURLY_COMMIT_PLAN.md`.
